## 写作 Skill

这份 Skill 以仓库里的 17 篇作品为参考，按文体整理了不同的写法：

- **日常随笔**：从具体遭遇说起，保留口语、自嘲和预期落差。
- **小说**：让动作、对白和心理变化一起推进故事，用前面的细节支撑后面的转折。
- **诗歌**：关注意象、复沓、分行和情绪的变化。
- **文言游记**：参考紧凑语序、对举，以及由景物转入所思的方式。

我希望它学到的是文字怎样走到下一句：为什么在这里停一下，为什么先说这件事，又为什么到最后才让一句话露出另一层意思。具体写什么、写给谁，仍然由当次任务决定。

Skill 中保留了少量原文片段作为参照，没有收录作品全文。对于邮件、报告等样本较少的文体，它只迁移适用的表达习惯，也可以结合新的同类范文继续调整。

### 使用

下载并解压 Skill 压缩包，保留下面两个文件的相对位置：

```text
write-like-me/
├── SKILL.md
└── references/
    └── user-writing-style.md
```

在支持自定义 Skill 的工具中，按该工具的方式加载整个 `write-like-me` 文件夹。也可以把这两个 Markdown 文件一起提供给 AI，并明确说明写作任务。例如：

> 请先阅读 SKILL.md 和 references/user-writing-style.md，参考其中日常记叙的写法，把我下面提供的经历写成一篇随笔。保留具体细节，事实以我提供的内容为准。

或者：

> 请参考这份写作风格指南润色下面的小说片段，保留人物关系、情节和叙述视角，重点调整句子节奏与对白。

使用随包提供的风格指南即可开始；Skill 中的额外写作检索流程需要相应工具支持，可在需要补充参考时使用。
